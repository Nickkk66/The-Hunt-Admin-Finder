This page cannot watch anything by itself. Roblox's API sends no CORS headers, so a browser on github.io is blocked from calling it, and your .ROBLOSECURITY cookie is httpOnly on roblox.com so JavaScript here could not attach it anyway. Any site claiming to do this in-browser is routing your cookie through someone else's server, which hands them your account.
